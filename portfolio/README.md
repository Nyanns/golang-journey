## 🌟 Architecture & Highlights

- **Work First, Words Second**: High-impact minimalist presentation inspired by Dieter Rams, Paco Coursey, and Linear design systems.
- **Flagship Production Systems**: In-depth architecture breakdown of [Lumiina](https://www.lumiina.art) (Go Clean Architecture, PostgreSQL GIN Trigram, Redis 7, React 19) and the formal QA/SDET automation suite (IEEE 829, Newman CLI, Jira LUM-5/LUM-6).
- **Verified Engineering Proof**: Direct verification links for LeetCode (31 solved), HackTheBox, Google Cybersecurity Professional Certificate (Score: 95), and Stanford Online / DeepLearning.AI (Score: 91).
- **Zero Glassmorphism / Anti-AI Slop**: Solid slate surfaces (`#080b10` dark / `#fafbfc` light), 1px tactile borders, and crisp typography using Inter and JetBrains Mono.
- **Lightning-Fast Performance**: Static edge compilation with sub-second LCP.

## 🚀 Local Development

```bash
# Navigate to portfolio directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build

# Preview build locally
npm run preview
```
